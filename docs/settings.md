# 設定(/settings)

`/settings` はBotの唯一のグローバルコマンドです。サーバーの中でだけ使えます。画面は押した人にだけ見えます。

設定は人ごとで、どのサーバーでも同じものを使います。会話をするには、言語モデルに使えるAPIキーを1つ以上登録し、言語モデルを選びます。判定モデルは任意で、選ばなければ言語モデルが判定もします。設定が済むまで、Botはその人の発言に答えません([会話の使い方](conversation.md#話しかける))。

## 画面の構成

トップには今の設定の一覧と、次のボタンがあります。

| ボタン | 中身 |
|---|---|
| APIキー | キーの登録・差し替え・削除 |
| モデル | 言語モデルと判定モデル。下に「用途別のモデル」 |
| ハーネス | Webツールと読み取りの範囲 |
| ルール | ルールの一覧と管理([ルール](rules.md#管理画面)) |
| コマンド | このチャンネルで使えるギルドコマンドと、自分のコマンド |
| Wasm | 自分の Wasm モジュールの一覧と登録([Wasm](wasm.md#登録と管理)) |

## APIキー

| キー | 使い道 |
|---|---|
| Claude API | 言語モデル・判定モデル。Webツールも使える |
| OpenAI | 言語モデル(GPT-5.5 以降の汎用モデル)・判定モデル。gpt-6-luna は判定専用。Webツールも使える |
| OpenRouter | 言語モデル・判定モデル。モデルIDを入力して選ぶ |
| GLM Coding Plan | 言語モデル・判定モデル・Webツール。Coding Plan のページで発行したキーが要る |
| TypeSafe | 判定専用のモデル(Jev) |
| Tavily | Webツール |

キーは AES-256-GCM で暗号化して保存します。画面に出すのは末尾4文字だけで、LLMやログには渡しません。

## モデル

- 言語モデル: 返事を書く、調べる、変更案やコードを作るときに使います。
- 判定モデル: 発言がBot宛てか、コマンドの返事を誰に見せるか、どのリアクションを付けるかを決めます。コードやルールの `judge()`・`rank()` と、会話の `judge` もこのモデルが答えます。軽いモデルか、判定専用のモデル(Jev・gpt-6-luna)が向いています。

OpenRouter はモデルが多いので、役割を選んでからモデルIDをモーダルに入力します(openrouter.ai/models に載っているID)。

### 用途別のモデル

用途ごとに別のモデルを選べます。選ばなければ元のモデルを使います。

| 用途 | 働き | 選ばないとき |
|---|---|---|
| 宛先の判定 | 自分が始めた会話で、発言がBot宛てかを決める | 判定モデル |
| コード | 調べもの・変更案・ルールのコードを書く | 言語モデル |
| リアクション | 文で返すか絵文字だけで返すかと、絵文字を決める。Botの発言へのリアクションへの応じ方も決める | 判定モデル |

コードのモデルを選ぶと、コードは応答のエージェントとは別のエージェントが書きます([会話の使い方](conversation.md#botが使う道具))。

## ハーネス

### Webツール

| 選択肢 | 働き |
|---|---|
| 言語モデルの標準 | 言語モデルが Claude・OpenAI・GLM Coding Plan なら、その検索を使う。ほかでは使わない |
| GLM Coding Plan | GLM Coding Plan の検索とページ読み取り。キーが要る |
| Tavily | Tavily の検索とページ読み取り。キーが要る(月1,000回まで無料) |
| 使わない | Webを使わない |

組み合わせで使えないとき(キーがないなど)は、画面に理由が出て、Webを使わずに答えます。運用側が環境変数 `WEB_SEARCH=off` にすると、全員のWebツールが止まります。

### 読み取りの範囲

Botは、チャンネルの全員が見られる情報だけを使います。それより広い情報が要るときの扱いを選びます。

- 毎回確認する: 広げる前にボタンで聞きます。
- 常に許可する: 聞かずに、自分が見られる範囲まで読みます。

## コマンド

押した人がこのチャンネルで使えるギルドコマンド(権限で判定。Administrator ならすべて)と、自分が作ったコマンドの一覧です。コマンド名はそのまま押せるリンクになっています。自分のコマンドを開くと、返事を見せる相手の変更、関連するルールへの移動、コマンドの削除(ルールごと消えます)ができます。

ギルドコマンドはルールから作ります([ルール](rules.md#コマンド))。
